# TerraDeskMatePlus · 泰拉桌伴 Plus

**全角色资源 + 本地 GPT-SoVITS 参考推理，不附带 41 套角色专属训练权重。**

Windows x64 便携运行版，应用版本 0.3.0；整理日期 2026-10-09。Plus 是资源组合名称，不代表功能升级或音色质量等级。

## 快速开始
1. 下载完整 Plus 发行包；若采用分卷，下载全部分卷后按发布说明合并/解压。
2. 将完整目录解压到可写位置，保持目录结构。不能只复制 EXE。
3. 双击 `TerraDeskMate.exe`。不需要安装 Node.js、npm 或系统 Python。
4. 在控制中心部署页选择角色和皮肤，保存后点击显示桌宠。启动只打开控制中心，不自动出场。
5. 先播放角色原声；需要 AI 聊天时再配置自己的服务商与密钥，需要合成语音时再启用本地参考推理。

## 包含内容
- 431 个角色、2835 个模型；随包动作、贴图、原声、台词、档案与参考资料。
- 共用 GPT-SoVITS/Python/Torch 环境、v2 通用预训练模型和角色参考录音。
- Electron 与应用运行文件、使用说明。
- **不包含**41 套角色专属 GPT/SoVITS 训练权重及其训练产物登记目录；不包含本地大语言模型。
- 不附带用户 API 密钥、私人聊天、私人记忆或私人录音。

## 占用与运行要求
Plus 运行文件逻辑大小约 **12.29 GB（11.45 GiB）**，文档与文件系统分配会增加少量空间；建议解压目标至少预留 15 GB，下载文件另算。实际压缩包大小尚未生成统计。

Windows x64；本地语音建议准备足够内存，16 GB 是参考配置，不是所有设备都已验证的最低门槛。CPU 推理较慢；CUDA 可用性取决于显卡和驱动。

## 验证边界
本机隔离启动、431 角色/2835 模型识别、默认不出场、代表资源加载通过。Plus 自带环境的 CPU 参考推理已对阿米娅日语、Aak 日语、Logos 中文生成有效音频。首次自动 GPU 冷启动超时，GPU 未作为本轮通过项。另一台物理电脑、全部角色的音色相似度未逐一验收。

参考推理不是角色训练，也不是保留原语调的音频到音频变声。全量版附带的训练产物同样不等于全部音色已通过人工验收。

## 发布形态
本GitHub仓库提供应用源码与构建资料；普通用户请从Release下载离线安装器或完整便携分卷，不需要npm。安装器所有同名BIN须与EXE放同一目录；便携分卷全部下载后用7-Zip打开第一卷。两种方式均不带41套角色训练权重。源码ZIP不是开箱即用程序，资源需用准备资源.ps1恢复。

## 开发者源码运行

Windows x64准备Node.js/npm；使用准备资源.ps1恢复全角色基础资源，按需加-IncludeSpeechRuntime恢复共用环境（不恢复专属训练权重）。执行npm ci、npm run build、npm start。普通用户不需要上述步骤。
