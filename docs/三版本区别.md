# 三版本区别

以下以 2026-10-09 的 0.3.0 交付内容为准，安装占用是逻辑文件大小，不包含私人存档、生成音频、下载包和文件系统额外分配。

| 项目 | 全量版 TerraDeskMate | Plus TerraDeskMatePlus | 轻量版 TerraDeskMateLight |
|---|---|---|---|
| 预装角色 | 431 个 | 431 个 | 阿米娅及通用敌人 |
| 全角色模型资源 | 2835 个模型 | 2835 个模型 | 其他角色按需导入 |
| 原声、台词、档案、参考 | 全部已提供资源 | 与全量保留资源相同 | 本体资源；其他角色基础包另装 |
| 共用本地 GPT-SoVITS 环境 | 有 | 有 | 无，需另行配置 |
| 通用 v2 预训练模型 | 有 | 有 | 不随本体提供 |
| 41 套角色专属训练权重 | 有，保留原验证状态 | **没有** | 本体没有，可选权重包另装 |
| 参考推理 | 随包环境支持 | **主要本地语音路线** | 准备环境后支持 |
| 内置本地大语言模型 | 无 | 无 | 无 |
| AI 聊天 | 用户自行配置服务 | 同左 | 同左 |
| 桌宠交互/动作/原声/字幕 | 保留 | 保留 | 保留，依赖已装角色资源 |
| 交付形式 | EXE + 17 BIN 安装器 | **完整便携目录** | 单 EXE 安装器 |
| 安装/展开占用 | 约 22.15 GB | 约 12.29 GB | 约 398 MB |
| 安装器下载大小 | 约 16.55 GB | 尚未生成 Plus 压缩包或安装器，不填估算 | 约 151.6 MB |

## 如何选择
- 想要全部角色、离线参考推理，但不需要此前训练的 41 套权重：选 Plus。
- 需要保存现有 41 套训练产物并自行试听验收：选全量版。
- 想先用阿米娅，减少初始下载和占用：选轻量版，按需补角色和语音环境。

Plus 相对全量只不复制 `resources/app/dist/assets/builtin/trained-voices` 专属训练产物目录。82 个权重文件合计约 9.85 GB；对应登记索引/数据清单一并不复制，以免宣称已提供不存在的权重。原声、参考音频和通用预训练模型不是该目录的训练权重，没有移除。

不附带权重不等于删除训练/导入相关界面。Plus 若以后导入用户权重，用户数据占用会增加；想保持参考推理版，不选择“已训练音色”路线即可。
