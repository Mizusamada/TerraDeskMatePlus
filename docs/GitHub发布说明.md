# Plus发布入口

仓库包含apps、services、packages、scripts等应用源码；大资源不直接进入Git，不使用收费Git LFS。普通用户下载Release离线安装器或便携分卷，源码克隆不等于可运行发行包。

- 安装版：完整下载TerraDeskMatePlus-Setup-0.3.0.exe及所有同名.bin，放同一目录，双击EXE。
- 便携版：完整下载TerraDeskMatePlus-0.3.0-win-x64.7z.001至末卷，放同一目录，用7-Zip打开001完整解压，运行TerraDeskMate.exe。
- 两种形式都保留431角色、2835模型、原声与共用GPT-SoVITS参考推理，均排除41套专属权重。
- 安装包未签名；CPU代表推理通过，GPU与另一物理电脑不承诺通过。安装器待验收/附件核对后公开。
- 不上传开发内部计划、私人配置/录音/聊天/密钥。
