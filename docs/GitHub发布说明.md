# GitHub 发布整理说明

## 当前已经整理好的内容
根 README 是公开首页；docs 包含 Plus 教程、三版本对比、验证边界及分类手册。根目录运行文件保持原样。没有创建 Plus 远程仓库，也没有上传、签名、生成 Plus 安装器或最终压缩发行包。

## 推荐发布结构
- GitHub 仓库：README.md、docs，以及原文件所需的版权/许可说明；清楚标注这是便携发行版介绍，不把它当源码工程。
- 发行资源：将完整 Plus 运行目录打成归档，采用满足上传平台当时限制的分卷/分包方案，保证用户能重建完整目录；附每个文件的 SHA256、总大小和解压说明。
- 不建议把12GB运行资源、Python环境或权重直接作为普通Git提交。无需因此自动购买或启用Git LFS。

## 发布前待做检查
1. 退出正在运行的程序，检查归档中不带运行后生成的私人配置、API Key、聊天数据库、个人录音、缓存或日志。应用原文件自带的第三方许可不要删。
2. 完整归档保留 EXE、DLL、locales、resources；不要只打包 EXE，也不要误加入原全量安装器。
3. 确认 `resources/app/dist/assets/builtin/trained-voices` 不存在；通用预训练模型和参考录音存在。
4. 生成最终归档校验值与准确压缩大小，在全新解压目录验证启动/模型/原声/CPU参考推理。
5. 发布文案填写实际文件名和实际下载地址；没有生成归档前不写虚假链接、大小或“已上传”。
6. 另一台物理电脑验收尚未完成，应保留说明；不能把本机启动当跨机器通过。

## 可直接用于 Release 的介绍
> TerraDeskMatePlus 0.3.0，Windows x64 便携版。提供431角色、2835模型与全量基础资源，附带一份共用GPT-SoVITS环境及通用v2模型，使用角色参考录音进行本地参考推理。不附带此前41套角色专属训练权重，不包含本地LLM或用户凭据。展开运行内容约12.29GB；请完整解压后运行TerraDeskMate.exe，不需要npm。CPU代表参考推理已验证，GPU与跨电脑兼容边界详见使用说明。

## 不要直接把本地计划和测试日志公开
项目内部计划记录在开发工作区，不放进发行根目录。公开文档只保留功能、操作、内容与诚实验证边界，不携带开发者用户路径、私人记录或后台上传状态。
