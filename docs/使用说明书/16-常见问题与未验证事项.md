# 常见问题

- 无角色：确认assets/builtin或基础包安装完整。轻量版除Amiya之外需从角色基础包目录导入；不要选错到content子目录。
- 无声音：检查静音/语音回复/输出模式；原声看文件与语种，本地AI看API/Python/权重，云端看凭据和额度。
- 看不到附件：预览可滚动，人物比例不会被宽附件拉小。桌面边缘的巨大作者特效可能自然出屏。
- 坐姿没有：模型没有Sit动作时不会自动创造它；打开窗口顶部承托也不能凭空生成作者动作。
- 权重导入后不能选择已验证音色：trained_unverified需独立试听验证，不直接跳状态。
- 模型低清或拼接线：记录角色/皮肤/动作和截图，确认当前版本；某些部件没有匹配的高清资源，保留原底图，不能保证全部源资源都同等高清。
- Git下载后PNG/权重无法读取：使用Git LFS拉取真实大文件，不能把指针文本当素材。只下载源码ZIP时也要确认素材内容已实际取得。
