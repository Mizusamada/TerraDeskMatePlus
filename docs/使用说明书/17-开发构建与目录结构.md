# Plus目录结构与开发边界

- TerraDeskMate.exe：便携运行入口。
- locales、DLL、PAK：Electron运行依赖。
- resources/app/dist：已编译应用与全角色基础资源。
- resources/app/speech-runtime：共用GPT-SoVITS环境和通用预训练模型。
- docs：Plus公开教程和分类手册。

本包没有开发源码工程，不在这里执行npm ci/build。开发请使用对应源码工程，不能把本目录称为可重建源码。Plus没有专属trained-voices目录，也没有Plus安装器。
