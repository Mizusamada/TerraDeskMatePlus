# Plus目录结构与开发边界

- TerraDeskMate.exe：便携运行入口。
- locales、DLL、PAK：Electron运行依赖。
- resources/app/dist：已编译应用与全角色基础资源。
- resources/app/speech-runtime：共用GPT-SoVITS环境和通用预训练模型。
- docs：Plus公开教程和分类手册。

GitHub仓库提供应用源码和构建资料；运行发行包不需要npm。开发源码需恢复基础资源与可选共用环境，再执行npm ci/build；Plus没有专属trained-voices目录，安装器和便携包都排除该目录。
