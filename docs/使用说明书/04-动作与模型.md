# 动作、模型和皮肤

动作页按当前角色/皮肤读取真实动画。可选分类、全部或自定义；动作旁设置速度、关联语音以及随机池。多选池只在所选集合中选择，不应跨角色取动作。Default是设置姿势，不作为普通可播放动作。

基建与战斗是资源组，正面与背面是作者模型视角。默认部署优先基建站姿；战斗动作和追击读取该角色匹配的战斗资源，不能拿另一个角色动作替代。

导入自定义模型入口适合单套Spine3.8骨骼、同名atlas及所有纹理页。不是角色基础包入口；想连人设/原声/字幕/参考都自动配置，应使用角色文件夹导入。自定义动作包还需骨骼/插槽签名一致，包含安全待机。

完整保留原始图集、校验依赖与已提供高清overlay。修复纹理按同骨骼/同atlas指纹匹配，无匹配则回退原资源。旧底图可能仍被校验、UV或回退路径引用，不能因画面看上去低清就直接删PNG/skel。

角色预览采用固定本体比例；坐卧自然变矮不动态补放大。某些作者轨道包含隐藏或过渡帧，不能把这些标记当成完整站姿模型替换。
