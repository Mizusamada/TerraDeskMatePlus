# AI聊天、人设与记忆

LLM配置页选服务商/兼容API，填Base URL、账号可用模型ID及其密钥，保存后可刷新模型列表。模型ID由服务决定，不凭下拉框猜权限。上下文/输出限制、温度、每日调用限制可配置；截图/图像功能还要求模型支持视觉。

聊天页输入文字发送。桌宠悬停快捷面板也可文字/语音对话；停止按钮取消当前请求。AI发声需要声音输出另行配置，能文字聊天不代表语音引擎已就绪。

人设页编辑角色名、对用户称呼、性格、说话习惯和示例。每个角色有独立档案与配置，不把Amiya卡强加给其他角色。导入基础包自动读取自己的档案；用户后续修改保留。

长期记忆页可添加、编辑、暂停或删除记忆；允许从聊天生成记忆时使用当前角色范围。历史文字和已保存声音均可回放；重放已存声音不重新生成。

密钥只存Windows用户数据中的加密存储，不在公开源码、角色包和个人迁移存档中。换电脑重新输入密钥；不要把个人数据目录公开。
