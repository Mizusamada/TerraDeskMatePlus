# 角色导入与资源管理

## 轻量版导入步骤
1. 找到角色基础包/角色名文件夹，完整下载或解压。
2. 保留manifest.json、content和使用说明.md；不要只下载PNG、MP3或skel。
3. 控制中心 → 下载管理 → 导入角色文件夹 · 自动配置。
4. 选择含manifest.json的角色目录，不是content/干员模型子目录。
5. 软件校验清单与文件指纹，复制到当前Windows用户数据目录；模型、皮肤、档案人设、原声、中文台词和当前角色参考自动登记并选中。
6. 点显示桌宠才会出场；导入不会运行Python、训练、云请求或自动生成桌宠。

## 音色权重另装
基础包只提供模型/皮肤/原声/字幕/参考。需要独立音色时，导入语音权重包/同一角色目录。Amiya已在轻量本体，不需重复基础包。其他角色先装基础包。未提供权重的角色有明确目录清单，不能把自动参考推理当成已有角色训练权重。

## 自动配置与手工设置
导入角色使用当前角色自己的资源根，不从Amiya借声音/台词。已保存的该角色个人设置优先保留；第一次导入按角色默认行为配置。主/辅助参考由角色目录登记；可在声音输出编辑并关闭自动参考。缺语言原声不把其他语言假冒所选语言。

## 删除与更新
在下载管理删除已安装的可选基础包/音色包。正在使用的角色或正在训练的包需先切换/结束任务。内置Amiya基础资源不能当成普通下载包删除。音色包删除不删除基础资源。再导入同一角色包会走校验及原子替换，不手动覆盖运行中的零散文件。

## 全量版
随包角色不必再下载基础包；直接选择。新增且不在目录中的角色才需要导入其基础包。此入口也接受独立音色包。
