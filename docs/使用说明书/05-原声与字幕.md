# 原声语音、字幕与录音

原声页选择当前角色的台词播放；可收藏、搜索、编辑用户台词、绑定到头/身体/脚/出场和动作。历史声音回放不会重新调用LLM/TTS。

发声模式可选日语、中文或混合，字幕仅中文。原声文件有实际语言；部分联动原声是英语、部分角色原声是中文。手动点击原声可播放实际语言，自动日/中池按模式选；没有所选语言时提示或无匹配，不把英语/日语标成中文。

静音、语音回复开关、文字显示和气泡分别控制。无声先看这些开关，再看文件和错误提示；不要不停重复收费试听。

导入/录制用户声音保存到该角色个人库，可以编辑中文字幕并设置交互绑定。麦克风录音不等于ASR，也不等于角色音色训练。私人录音和存档不属于公开资源目录。
