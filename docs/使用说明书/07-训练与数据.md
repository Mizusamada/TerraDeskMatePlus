# 角色语音训练

进入当前角色训练页面，先准备该角色自己的音频和准确逐字原文，选语言、主/辅助参考。参考配置/清单自动填充不是模型训练。

本地ASR候选带待核对状态，必须人工核对后才可用于正式训练导出；中文翻译不等于日语原文。不要把其他角色录音加入当前角色数据。

导出训练清单与训练计划，检查环境、基础权重、保存目录和硬件；启动训练执行固定本地脚本，产物放该角色用户目录。状态区分not_started、dataset_ready、training、trained_unverified、verified、failed。

训练会消耗CPU/GPU、时间和存储；程序不会替用户租GPU或购买模型。进行中任务可停止，只停止应用拥有的进程。失败看任务日志，勿重复启动多条任务争用同一GPU。生成权重后仍需独立样本试听，正确音色不能仅凭文件大小判断。

本仓库的已有权重清单只列真实产物，没有的角色明确未提供。训练脚本随源码，训练缓存/优化器检查点和私人语音不随公开目录。


## Plus特别说明
本包没有预装41套独立训练产物；本章是训练功能说明，不是已有训练成果声明。普通参考推理不需要开展训练。
