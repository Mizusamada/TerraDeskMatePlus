# 桌宠显示、实例与边缘行为

部署页选角色、皮肤、基建/战斗或自定义动作组；保存后显示。顶部当前控制用于选中实例；每个实例/角色有自己的设置、聊天和记忆。多个显示操作可创建不同实例，数量有上限；关闭某只与关闭控制中心不是同一个操作。

拖拽真实人物移动；透明空白不应当作人物。松开后按重力、工作区和窗口承托配置落下。开启站在其他窗口顶部才会识别外部窗口；开启沿四边行走才启用墙面/倒立移动。移动保持原窗口宽高，避免高DPI漂移。

头默认随机日常、身体当前角色Interact/信赖触摸、脚默认角色自有提问。可在交互映射里改动作/语音/静音/多选随机池。

闲置动作与闲置语音各自开关、间隔独立。手动模式/正在聊天或拖拽会影响自动行为。坐姿按臀部接触点贴面，站姿按脚贴面；某些原模型没有Sit，则不能凭空播放作者未提供的动作。

显示区域为容纳附件可以比人物大，人物本体标尺不把武器/特效纳入。预览本体统一280 CSS px，宽附件可滚动；用户缩放滑块是主动改变桌宠大小。窗口内预览不修改桌面碰撞和坐姿。

隐藏停止遮挡；显示触发出场。单次动作结束回待机，不把Default静态姿势当普通动作循环。角色资源中第二个出场保留在动作列表，不默认连续播放。
