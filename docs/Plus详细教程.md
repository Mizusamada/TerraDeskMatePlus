# Plus 详细新手教程

## 1. 完整解压与第一次启动
将完整发行目录解压到可写文件夹，双击根目录 `TerraDeskMate.exe`。`resources`、`locales`、DLL、PAK 和 EXE 必须一起保留。Plus 已编译，无需 npm ci、npm build、系统 Python 或 D 盘固定路径。新电脑不需要开发者的资源盘。

Plus同时提供安装版和便携版：安装版下载EXE及全部同名BIN到同一目录，双击EXE；便携版完整解压后直接运行。安装向导可创建快捷方式。关闭窗口不一定代表完全退出，更新/移动前从托盘退出应用。若遇 Windows 安全提示，确认下载来源与发布文件校验值，不以关闭安全软件作为常规解决方法。

## 2. 不配置 AI 也可以先玩
1. 打开控制中心的部署页，选择角色、皮肤与动作组。
2. 保存后点击显示桌宠，才会触发出场。启动本身不生成桌宠。
3. 拖动人物位置；调整大小、置顶、重力、窗口顶部承托和全屏安静模式。
4. 在动作页选择模型实际提供的动作；单次动作结束回待机。模型没有 Sit 时不会凭空增加坐姿。
5. 原声页选择台词试听；头/身体/脚互动映射可自定义。闲置动作、闲置语音分别开关。
6. 悬停快捷面板可以进入对话、动作、语音或取消当前桌宠。多实例选择正确的当前控制对象再改设置。

原声播放、显示和动作不需要云端密钥，也不需要启动 Python。

## 3. 三条声音路线不要混淆
- **原声**：播放已有角色录音，没有生成新的文字语音。
- **本地 GPT-SoVITS · 参考推理**：通用模型 + 当前角色录音/原文合成新文字，这是 Plus 主要本地路线。
- **已训练音色**：需要角色专属 GPT/SoVITS 权重。Plus 默认不提供，不要选择它来测试首次运行。

参考推理不等于训练，不保证每个角色同样相似；也不是 RVC/Seed-VC 音频到音频转换。

## 4. 配置本地参考推理（重点）
### 检查随包路径
在声音输出页选择本地 GPT-SoVITS / 参考推理。优先使用自动识别/随包模板，并确认路径属于当前 Plus 目录。

下列路径均以 Plus 根目录为起点：
- 环境根：`resources/app/speech-runtime/GPT-SoVITS`
- Python：`resources/app/speech-runtime/GPT-SoVITS/env/python.exe`
- GPT 通用模型：`resources/app/speech-runtime/GPT-SoVITS/GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt`
- SoVITS 通用模型：同一目录内 `s2G2333k.pth`
- 参考资源根：`resources/app/dist/assets/builtin/干员语音`

界面要求绝对路径时，在上述相对路径前加你实际解压目录，不能照搬别人的 D 盘地址。不要选 `trained-voices`，Plus 没有这个目录。

### 启动和试听
1. 确认声音输出模式为参考推理，打开需要的语音回复开关，关闭静音。
2. API 使用本机地址，例如 `http://127.0.0.1:9880`；端口须与本地服务一致，不要指向陌生远程地址。
3. 开启自动角色参考，让主参考、辅助参考、原文与语言随当前角色切换；保存设置。
4. 首次排障建议选 **CPU**。点击启动本地服务，等就绪后再试听。首次加载比播放原声慢，不要连续重复启动。
5. 正常后再尝试 auto/CUDA。GPU 需要兼容驱动与足够显存；本轮 Plus CPU 验证通过，auto/GPU 首次冷启动曾超时，不承诺所有 GPU 可直接运行。
6. 结束时只停止应用自己启动的服务，不结束其他 Python 进程。

### 手工参考配置
选择当前角色自己的清晰录音，主参考通常 3–10 秒；填写录音实际逐字原文与参考语言，中文译文不能冒充日语原文。输出语言和参考语言是两项不同设置。部分自动转写仍需人工核对，不宣称全部准确。手工修改前可关闭自动角色参考，避免切换角色自动替换。

## 5. AI 文字聊天和 AI 发声
在 LLM 配置页选兼容服务、填写 Base URL、自己的 API Key 与账号有权限的模型 ID，保存后测试文字聊天。Plus 不包含本地大语言模型；自行部署本地 LLM 时，需要自己的服务地址与模型。

先确保文字回复正常，再开启本地语音回复。文字可用不意味着 TTS 已启动。云端 LLM、云语音、ASR 可能各自收费；历史已有音频回放不应重新生成。密钥不写进公开 README、截图、角色包或 GitHub。

## 6. 语言、字幕与原声
AI 和原声可设中文、日语或混合；字幕只显示中文。原声的实际录音语言取决于资源，缺某语言不能靠改标签得到。声音、聊天文字、角色旁字幕分别控制；声音缺失先查静音、输出模式、语音回复开关及语言资源。

## 7. 角色、个人设置与可选导入
随包 431 角色无需再导入基础包。新增角色可使用下载管理的“导入角色文件夹 · 自动配置”，选择含 manifest.json 的角色目录，不选 content 子目录。基础包不等于音色权重包；导入不会自动训练或发起云请求。角色设置、人设、聊天、记忆按角色/实例管理，切换时确认当前控制对象。

## 8. 其他功能入口
- 人设/记忆：编辑称呼、性格、示例；记忆按确认规则保存，可查改、暂停和删除。
- 聊天历史/收藏：回看文字、回放已经保存的声音；撤回与清空前确认对象。
- 麦克风/ASR：用户显式开启；腾讯实时识别需独立凭据、服务权限和麦克风权限，LLM 密钥不能替代。
- 趣味/提醒：喝水、时段提醒、番茄钟、源石虫事件、全屏安静模式。
- 外观：气泡、字幕大小、动效等。模型特效可能宽于人物本体。
- 电脑权限：白名单、逐次确认、审计、紧急停止；不提供绕过 UAC、付款或密码的能力。
- 变声工作台：真正保留语调需要独立音频到音频环境/模型；GPT-SoVITS 不是已完成的 Seed-VC/RVC 部署。
- 训练页：界面保留，但本包无 41 套训练产物。导出数据不等于训练完成，进行真实训练前核对数据/依赖/硬件。

各入口操作细节见[分类说明书](使用说明书/00-目录.md)。未配置的外部服务不能靠本包自动取得权限。

## 9. 存档、更新与卸载便携版
在存档页导出个人 `.terrasave` 并保管好；不公开上传。存档不含 API Key，新电脑重配密钥。个人数据不因复制应用目录自动迁移。切换版本或更新前退出应用并备份存档；三个版本可能共用既有用户数据，Plus 不是全新的个人配置隔离空间。

若旧配置仍指向之前训练权重或旧目录，重新选参考推理并保存当前 Plus 通用模型路径；不要删除原权重来排障。便携版本身无需卸载器，关闭应用后可移走/删除应用目录；清理个人数据是另外一项操作，先备份且确认目标。

## 10. 常见问题
- 只复制 EXE 启动失败：恢复完整目录，不单独补一个 DLL 猜修复。
- 参考推理没声音：查服务就绪、API 端口、Python/通用模型路径、参考音频、静音与开关；先 CPU 单次试听。
- 权重页尚未开始：Plus 正常不预装独立训练权重，不是全角色基础资源丢失。
- 云端 401/403：检查权限/区域/模型/凭据，不无限重试收费服务。
- 在别人电脑不运行：提供 Windows 架构、错误提示、路径、显卡与驱动信息；不要发送密钥或私人聊天。
- GitHub 克隆后只有文档：便携运行资源应从完整发行包取得，文档仓库不是全部二进制。


## 安装版下载步骤
在Release下载TerraDeskMatePlus-Setup-0.3.0.exe及所有同名.bin，放同一目录。核对INSTALLER-SHA256.json后双击EXE，选择当前用户安装位置和快捷方式。安装器未签名。不要只下载EXE，不需要Node.js/npm。安装后从开始菜单启动；卸载保留用户数据，删除个人数据前先导出存档。

## GitHub源码类型
仓库包含apps/services/packages/scripts，与全量和轻量同类。GitHub自动统计语言；源码ZIP不含全量大资源，普通用户必须选Release安装器或便携分卷。
